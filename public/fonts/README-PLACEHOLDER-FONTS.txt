Bezoria.otf and Praise.ttf in this folder are TEMPORARY placeholders in
this build environment only.

They currently contain Playfair Display and Italiana (both SIL Open Font
License, free to use/redistribute) renamed to the filenames the project
expects, purely so `npm run build` succeeds here.

If you already have your real Bezoria.otf and Praise.ttf sitting in this
folder in your own copy of the project, just leave them — the code already
points at these exact filenames, so your real fonts will load automatically
with no further changes.
